# API Contract

This document describes the initial logical API. Exact schemas and authentication requirements will be finalized during implementation.

## Conventions

- JSON is used for metadata and calculation requests.
- Multipart upload is used for source files.
- IDs are opaque values generated by the backend.
- Timestamps use UTC.
- Errors return a stable error code, human-readable message, and optional details.

## Health

### `GET /health`

Returns application and dependency status.

## Clients

- `POST /clients` - create a client
- `GET /clients` - list clients
- `GET /clients/{client_id}` - retrieve a client
- `PATCH /clients/{client_id}` - update a client
- `POST /clients/{client_id}/archive` - archive a client

Client and project routes are available without authentication in the current local single-user MVP.

## Projects

- `POST /projects` - create a project
- `GET /projects` - list projects
- `GET /projects/{project_id}` - retrieve a project
- `PATCH /projects/{project_id}` - update a project
- `POST /projects/{project_id}/archive` - archive a project

## Files and Processing

- `POST /projects/{project_id}/files` - upload a source file
- `GET /projects/{project_id}/files` - list source files
- `GET /projects/{project_id}/files/{file_id}` - retrieve file metadata
- `GET /projects/{project_id}/files/{file_id}/download` - download a permitted file
- `POST /projects/{project_id}/files/{file_id}/process` - start or retry processing
- `GET /projects/{project_id}/files/{file_id}/extraction` - retrieve the latest normalized extraction
- `GET /projects/{project_id}/processing` - list processing jobs
- `GET /projects/{project_id}/processing/{job_id}` - retrieve job status and warnings

Supported upload extensions are `.pdf`, `.dxf`, `.csv`, `.txt`, `.tif`, and `.tiff`. Uploads are limited to 50 MB, stored under the configured local storage path, and identified by a SHA-256 checksum. A duplicate checksum within the same project returns `409`. Processing currently runs synchronously and records `processing`, `completed`, or `failed` status. TIFF/TIF processing records raster metadata and reports that OCR is not enabled; asynchronous execution remains a later optimization.

## Site Model

- `GET /projects/{project_id}/site-model` - retrieve the active revision
- `GET /projects/{project_id}/site-model/entities` - list filtered entities
- `GET /projects/{project_id}/revisions` - list project revisions
- `GET /projects/{project_id}/revisions/{revision_id}` - retrieve a revision
- `POST /projects/{project_id}/site-model/revisions/from-extraction/{file_id}` - accept an extraction into a site-model revision
- `GET /projects/{project_id}/site-model/revisions` - list site-model revisions
- `GET /projects/{project_id}/site-model/revisions/{revision_id}/entities` - list revision entities

## Calculations

### `POST /projects/{project_id}/calculations`

Accepts a calculation type, input entity IDs or explicit points, units, and optional revision ID. Returns the formula, normalized inputs, result, unit, assumptions, and source references.

Initial calculation types:

- `distance`
- `elevation`
- `slope`
- `area`

- `perimeter`

Calculation responses include normalized inputs, formula, result, unit, assumptions, source entity IDs, and optional revision ID. The current engine supports deterministic distance, area, perimeter, and slope calculations; elevation lookup/statistics are still pending.

## Summaries and Questions

- `POST /projects/{project_id}/summaries` - generate a site summary
- `GET /projects/{project_id}/summaries` - list generated summaries
- `POST /projects/{project_id}/questions` - ask a source-grounded question
- `GET /projects/{project_id}/questions` - list previous questions and answers

## Error Categories

- `invalid_request`
- `not_found`
- `unsupported_file`
- `processing_failed`
- `invalid_geometry`
- `unit_mismatch`
- `insufficient_data`
- `provider_unavailable`
- `internal_error`

## API Rules

- Never expose arbitrary filesystem paths.
- Validate project ownership before accessing project data.
- Limit upload size and accepted media types.
- Return warnings when extraction is incomplete.
- Do not return an AI-generated measurement without source context or a clearly stated limitation.
